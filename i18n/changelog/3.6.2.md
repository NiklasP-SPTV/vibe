# 3.6.2

- Second speaker model for comparison: with speaker recognition on, the start dialog offers "Neu: Nemotron (bis 8 Sprecher, Test)" next to the existing model. Nemotron comes from the original Vibe project (#1619), tells up to eight speakers apart and splits a line where the speaker changes mid-sentence. The existing model stays the default and works exactly as before. On a 51-minute interview Nemotron matched Trint's speakers in 97 % of words, the existing model in 95 %.
- The engine now ships FFmpeg 9.0.2, pinned by version and SHA-256 (IT review H2). The macOS packages had an outdated FFmpeg 8.0 with known memory bugs.
- Engine server-v0.6.10-sptv.2.
