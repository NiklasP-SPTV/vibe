# 3.5.0

- New start dialog: every file that comes in, including files added to a running session, opens one window for start timecode, quality, spoken language, speaker recognition, burned-in timecode video and translation.
- More complete transcripts with more accurate timecodes: the decoder starts at temperature 0 and keeps its full context again (224 tokens instead of 64). On a 51-minute interview this cut the text missing against Trint from about 190 words to about 50, and removed timecode offsets of up to ten seconds. Settings still on the old defaults move over once.
- Much faster on PCs with both an integrated and a dedicated graphics card: with the device left on Auto, the dedicated GPU is used. A 51-minute interview took under two minutes on an RTX 5080.
- Exports read like documents: consecutive lines of one speaker become paragraphs (PDF, Word, text, Markdown, HTML, JSON, CSV), each with its starting timecode. Subtitles keep their short cues; a switch in the export dialog turns it off.
- The "Maximale Qualität" mode is prepared but stays off until the next version: with the current engine, large-v3 brought no gain over the standard model.
