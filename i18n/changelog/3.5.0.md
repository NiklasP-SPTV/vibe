# 3.5.0

- New start dialog: every file that comes in, including files added to a running session, opens one window for start timecode, quality, spoken language, speaker recognition, burned-in timecode video and translation.
- Two quality modes. Standard uses the model chosen in settings. Maximale Qualität uses the full large-v3 model with voice activity detection and an accuracy-first decoder; it takes about 3–5 times as long and downloads the model once.
- Exports read like documents: consecutive lines of one speaker become paragraphs (PDF, Word, text, Markdown, HTML, JSON, CSV), each with its starting timecode. Subtitles keep their short cues; a switch in the export dialog turns it off.
- Fewer missing words: the decoder now starts at temperature 0 instead of 0.4.
