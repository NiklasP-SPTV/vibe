# 3.4.0

- Translate transcripts with DeepL: switch it on in the start screen, pick the source (or let DeepL detect it) and target language. Every segment keeps its timecode and speaker.
- Switch between original and translation in the transcript view, translate or re-translate any saved transcript, and export either text in every format.
- New Translation settings: DeepL API key (free keys are recognised and flagged for non-sensitive material only), connection check with character usage, and defaults for the start screen.
