# 3.6.3

Hardening after the IT security review of 3.6.1. Includes everything from 3.6.2 (Nemotron as a second speaker model for comparison, FFmpeg 9.0.2).

- No telemetry: usage statistics are removed completely.
- FFmpeg only reads local files, and the bundled FFmpeg is used before one on the system.
- The app window runs under a content security policy; developer tools are no longer in release builds. Tauri 2.12.5.
- Summaries and answers from AI models never load images or follow links.
- Before a transcript is first sent to a cloud AI service, the app asks; the summary menu names where the text goes. Automatic summaries only run with a local model.
- The local engine accepts requests only with a key the app creates on each start, and only for this computer.
- Every model download and yt-dlp is checked against its published SHA-256.
- Leftover copies of recordings are cleaned up; the log records warnings and errors only.
- Phone handoff is switched off.
- Error reports go to this fork's project, and only when "Melden" is clicked.
- Updates: once a version is approved, installed apps are offered it automatically.
- Engine server-v0.6.10-sptv.3.
